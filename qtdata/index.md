# 简介

量潮数据工程工具链（qtdata），三件套架构：CLI + Provider + Studio。

## 背景和动机

数据工程涉及大量重复性工作：需求梳理、规格定义、进度跟踪、交付验收。这些环节分散在不同的工具和文档中，缺乏统一的流程载体。

qtdata 的目标是将数据工程的核心流程串联起来，从需求到交付形成闭环。

## 方案

- **CLI**：命令行工具，处理数据需求文档（DRD）的生成、解析和转换
- **Provider**：后端服务，管理项目、任务、交付物等核心数据模型
- **Studio**：前端界面，提供可视化的项目看板和交付管理

三件套可独立使用，也可组合部署。
